# Monika Swift

A SwiftUI application built with Swift Package Manager.

## Features

- Modern SwiftUI interface
- Cross-platform support (macOS 13+, iOS 16+)
- Simple counter example to get you started

## Requirements

- Swift 6.1 or later
- macOS 13+ or iOS 16+
- Xcode 15+ (recommended)

## Getting Started

### Building the Project

```bash
swift build
```

### Running the Project

```bash
swift run
```

### Opening in Xcode

You can open this project in Xcode by double-clicking the `Package.swift` file or running:

```bash
xed .
```

## Project Structure

```
monika-swift/
├── Package.swift          # Swift Package Manager configuration
├── Sources/
│   ├── main.swift        # App entry point
│   └── ContentView.swift # Main SwiftUI view
└── README.md
```

## Next Steps

- Customize the `ContentView.swift` to build your app
- Add more views and models as needed
- Explore SwiftUI components and modifiers
- Add dependencies in `Package.swift` if needed
